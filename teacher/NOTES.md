# 两层随机游走实现说明

## 方向和数值约定

- Falcor `IBSDF` 中的方向都指向远离表面的一侧。
- `eval(wi, wo)` 返回 `f(wi, wo) × abs(wo.z)`。
- 数据生成器把 `wi` 作为固定观察方向，把 `wo` 作为入射光方向。因此缓存的 tile 已经包含光照余弦，后续训练或积分不能再次相乘。
- pbrt-v4 `LayeredBxDF::f(wo, wi)` 返回未乘光照余弦的 BSDF。交叉验证会先乘 `abs(wi.z)`，再与本项目结果比较。
- `interfaces.slang` 的单界面函数只返回 BSDF `f`；tile kernel 在最外层恰好乘一次 `abs(wo.z)`。
- v0 中的 `roughnessX/Y` 直接表示 GGX α，不是还需要平方或重映射的“感知粗糙度”。

## 两界面状态机

从材质上方观察反射时，一条路径按下面的顺序处理：

1. 先加入顶层粗糙介电界面的直接反射。
2. 采样穿过顶层、进入中间介质的透射。为降低方差，参考实现强制选择透射分支，并把 Fresnel 权重保留在 `f/pdf` 中；期望值不变。
3. 路径向另一侧界面传播，同时应用吸收透射率，或者采样一次体散射事件。
4. 到达底层界面后，先计算它朝指定出射方向的贡献，再采样一次反射继续路径。
5. 回到顶层界面时，先计算逃逸到指定出射方向的贡献；若继续随机游走，则强制反射并在路径权重中保留 Fresnel 因子。
6. 深度超过 3 后，对低吞吐路径使用俄罗斯轮盘赌终止。

Falcor `LayeredBSDF` 使用单路径、忽略横向位置的估计器。pbrt-v4 `LayeredBxDF::f()` 还会预采样出射方向，并使用下一事件估计（NEE）和多重重要性采样（MIS）。两者的单条样本不需要相同；在方向约定、颜色参数和余弦约定一致时，收敛后的均值应当一致。

## 与 Falcor 内置实现交叉检查时发现的问题

Falcor 8.0 的 `LayeredBSDF.eval()` 在俄罗斯轮盘赌拒绝路径时，会在一个返回 `float3` 的函数中执行 `return false`。这会把已经累计的贡献也变成零。相位函数采样失败的分支有同样问题，因此一旦俄罗斯轮盘赌开始执行，内置估计会偏低。

这个判断通过控制 `maxDepth` 得到验证：

- `maxDepth=4` 时还不会触发俄罗斯轮盘赌。本项目实现与 Falcor 在五个方向的灰色涂层漫反射切片上，最大只差 1.11 个合并标准误差。
- `maxDepth=32` 时，pbrt-v4 和本项目实现都会因为加入非负的多次反射路径而上升，未修改的 Falcor 结果却下降。
- pbrt 的透明夹层测试必须使用接近零的光学厚度。`albedo=0`、`thickness=1` 表示纯吸收介质，不是真空。

因此批量训练参考固定使用 `layered_walk.slang`。未修改的 Falcor `LayeredBSDF` 只在关闭俄罗斯轮盘赌时用于检查接口和状态机，不用于生成监督数据。加入参考 pbrt 的表面/体积 NEE 与 MIS 后，深路径的真空、纯吸收和 HG 散射五方向切片与 pbrt 的最大相对差分别为 0.182%、0.108% 和 0.267%。

pbrt 交叉验证应使用多个规模适中的独立批次。单次调用百万样本的 `LayeredBxDF::f()` 时，函数会先用 fp32 保存 `nSamples × direct`，再累加较小的间接项；两者数量级相差太大时，小贡献会损失精度。

## v0 对参与介质的限制

纯吸收介质允许 RGB 三个通道使用不同的吸收系数。

当介质包含体散射时，v0 令 RGB 三个通道的总消光系数 `sigma_a + sigma_s` 相同。这样一条随机采样的自由飞行距离可以同时用于三个颜色通道，不需要实现光谱 null-collision tracking。颜色仍可通过每个通道不同的散射反照率表现，HG 相位参数 `g` 也可以变化。

这是 v0 为简化采样而设定的数据范围，不表示真实介质通常具有无色的总消光。未来若研究强烈的波长相关平均自由程，需要放宽这一限制并更换体传输采样方法。

## 第一组验证材质

- 粗糙介电涂层 + Lambert 漫反射基底；
- 粗糙介电涂层 + 粗糙导体基底；
- 第一轮方向切片不启用体散射；
- 观察角固定为 0°、30°、60°；
- 入射光在切线平面内从 −80° 扫描到 80°；
- 每个 bin 保存 A/B 两组独立均值和方差，并逐步增加样本数直到达到目标置信区间。
